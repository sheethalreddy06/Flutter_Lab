# Experiment 7: Data Persistence Using Google Cloud Firestore

## 📌 Aim
Cloud student registration and real-time StreamBuilder retrieval with Firestore

## 🛠️ Concepts & Widgets Covered
- **Directory**: `exp_07/`
- **Entrypoint**: `lib/main.dart`

## 🚀 How to Run

Navigate to this directory and run on Chrome or Windows:

```bash
cd exp_07
flutter pub get
flutter run -d chrome
```

Or run directly on Windows Desktop:

```bash
flutter run -d windows
```
