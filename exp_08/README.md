# Experiment 8: Searching Information in Google Firestore Database

## 📌 Aim
Search student records in Cloud Firestore using range queries

## 🛠️ Concepts & Widgets Covered
- **Directory**: `exp_08/`
- **Entrypoint**: `lib/main.dart`

## 🚀 How to Run

Navigate to this directory and run on Chrome or Windows:

```bash
cd exp_08
flutter pub get
flutter run -d chrome
```

Or run directly on Windows Desktop:

```bash
flutter run -d windows
```
