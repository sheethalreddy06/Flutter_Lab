# Experiment 5: Implementation of Navigation and Routing

## 📌 Aim
Multi-screen navigation, named routes, argument passing and result handling

## 🛠️ Concepts & Widgets Covered
- **Directory**: `exp_05/`
- **Entrypoint**: `lib/main.dart`

## 🚀 How to Run

Navigate to this directory and run on Chrome or Windows:

```bash
cd exp_05
flutter pub get
flutter run -d chrome
```

Or run directly on Windows Desktop:

```bash
flutter run -d windows
```
