# Experiment 2: Adaptive and Responsive UI Design

## 📌 Aim
ShopEase responsive e-commerce catalog with LayoutBuilder and breakpoint grid

## 🛠️ Concepts & Widgets Covered
- **Directory**: `exp_02/`
- **Entrypoint**: `lib/main.dart`

## 🚀 How to Run

Navigate to this directory and run on Chrome or Windows:

```bash
cd exp_02
flutter pub get
flutter run -d chrome
```

Or run directly on Windows Desktop:

```bash
flutter run -d windows
```
