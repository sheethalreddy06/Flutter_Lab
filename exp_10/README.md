# Experiment 10: Manual User Login Authentication Using Firestore

## 📌 Aim
Secure authentication with SHA-256 salt password hashing and Firestore storage

## 🛠️ Concepts & Widgets Covered
- **Directory**: `exp_10/`
- **Entrypoint**: `lib/main.dart`

## 🚀 How to Run

Navigate to this directory and run on Chrome or Windows:

```bash
cd exp_10
flutter pub get
flutter run -d chrome
```

Or run directly on Windows Desktop:

```bash
flutter run -d windows
```
