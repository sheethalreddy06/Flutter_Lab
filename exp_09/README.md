# Experiment 9: Update Information in Google Firestore Database

## 📌 Aim
Update existing student details in Cloud Firestore by register number

## 🛠️ Concepts & Widgets Covered
- **Directory**: `exp_09/`
- **Entrypoint**: `lib/main.dart`

## 🚀 How to Run

Navigate to this directory and run on Chrome or Windows:

```bash
cd exp_09
flutter pub get
flutter run -d chrome
```

Or run directly on Windows Desktop:

```bash
flutter run -d windows
```
