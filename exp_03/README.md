# Experiment 3: Add Interactivity to App - Input and Forms

## 📌 Aim
Interactive product store with search filter, category chips, and sorting

## 🛠️ Concepts & Widgets Covered
- **Directory**: `exp_03/`
- **Entrypoint**: `lib/main.dart`

## 🚀 How to Run

Navigate to this directory and run on Chrome or Windows:

```bash
cd exp_03
flutter pub get
flutter run -d chrome
```

Or run directly on Windows Desktop:

```bash
flutter run -d windows
```
